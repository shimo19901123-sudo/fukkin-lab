腹筋LAB v1.2（ショートカット歩数連携版）
=====================================

機能：体重・ウエスト記録／食事・筋トレ記録／歩数記録（ショートカットからの取込）／7日間歩数グラフ／JSONバックアップと復元。

アップデート方法：
  1. 既存GitHub Pagesのリポジトリに「abs_lab_app」フォルダ内のファイルを上書きアップロード。
  2. 元々GitHub Pagesがルート公開なら、フォルダ内のファイルをリポジトリのルートに置くこと。
  3. 既存データの保存キーは abs_lab_jp_v1 のまま維持しているため、同じURL・同じホーム画面アプリ内で更新すれば原則引き継ぐ。作業前に「全データ保存（JSON）」でバックアップを推奨。

歩数連携（iPhone）：
  1. ショートカットを新規作成し「腹筋LAB 歩数取得」と命名。
  2. 「ヘルスケアサンプルを検索」で種類：歩数、開始日：今日、取得件数制限：オフ。
  3. 「ヘルスケアサンプルの詳細を取得」で「値」を指定。
  4. 「統計を計算」で「合計」を指定。
  5. 「クリップボードにコピー」で合計値をコピー。
  6. 腹筋LABホームで「ショートカットの歩数を取り込む」をタップ。

注意：
- ヘルスケアのアクセス許可はiPhoneの「ショートカット」に対して与える。Webサイトにヘルスケア権限を与える必要はない。
- これはショートカット経由の『操作付き取込』であり、端末を触らずに完全自動でアプリのデータを同期する機能ではない。
- iOS実機での動作は未検証。Apple WatchとiPhoneなど複数ソースがある場合は集計値がヘルスケア表示と一致するか初回に確認。
- Safariとホーム画面PWAは別のlocalStorageになることがある。URLでの自動取込は、開いた側の保存領域に保存される。推奨はクリップボード取込。
- 健康データを外部に送信しない設計。
